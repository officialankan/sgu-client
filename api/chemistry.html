Groundwater Chemistry API#

The groundwater chemistry API provides access to water quality measurements from monitoring stations, including chemical composition, pH, conductivity, and other parameters.

Overview#

The chemistry API is accessed through client.chemistry and provides methods to query chemical measurements from groundwater monitoring stations.

Data comes from SGU’s Grundvattenkvalitet, analysresultat och provplatser (version 2) OGC API, which has two collections: sampling sites (provplatser) and analysis results (analysresultat).

Quick Example:

from sgu_client import SGUClient

client = SGUClient()

# Find a sampling site and its national site ID
site = client.chemistry.get_sampling_site_by_name(site_id="TTK-442-M")
national_site_id = site.properties.national_site_id

# Get analysis results for the site (national_site_id is the fastest lookup)
results = client.chemistry.get_results_by_site(
    national_site_id,
    tmin="2020-01-01",
    tmax="2024-01-01",
)

# Get all lead measurements since 2020
lead = client.chemistry.get_results_by_parameter("Bly", tmin="2020-01-01")

# Convert to pandas DataFrame for analysis
df = results.to_dataframe()
print(df[['sampling_date', 'parameter_name', 'measurement_value', 'unit']].head())

Chemistry Client#

The GroundwaterChemistryClient provides methods to query groundwater chemistry data.

Key Methods:

  • get_sampling_sites() / get_analysis_results() - Query the collections directly with OGC API filters

  • get_sampling_site_by_name() / get_sampling_sites_by_names() - Find sites by site_id, site_name or national_site_id

  • get_results_by_site() / get_results_by_sites() - Get analysis results for one or more sites

  • get_results_by_parameter() - Get analysis results for a chemical parameter, optionally per site

Identifying sites:

Analysis results reference sampling sites only by national site ID (nationellt_provplatsid). Passing national_site_id is therefore the recommended and fastest option; site_id (platsbeteckning) and site_name (provplatsnamn) trigger an additional request to look up the site, and log a warning.

Filtering Options:

  • bbox: Spatial filter (bounding box)

  • datetime: Temporal filter (ISO 8601 datetime or interval)

  • filter_expr: CQL filter expression, e.g. "parameternamn='Bly' AND provtagningsdatum>='2020-01-01'"

  • limit: Maximum number of results to return (paginated automatically)

Common Parameters:

Parameters are identified by SGU’s Swedish parameter names (parameter_name), for example:

  • pH

  • Konduktivitet (electrical conductivity)

  • Klorid, Svavelsulfat (major ions)

  • Nitratkväve (nutrients)

  • Bly (trace elements)

get_results_by_parameter(parameter, national_site_id=None, site_id=None, site_name=None, tmin=None, tmax=None, limit=None, **kwargs)[source]#

Get analysis results filtered by chemical parameter (e.g., pH, nitrate).

This convenience method makes it easy to retrieve all measurements for a specific chemical parameter, optionally filtered by site(s) and time range. Sites are identified the same way as in get_results_by_site(): national_site_id is recommended, while site_id or site_name require an additional API request.

Parameters:

  • parameter (str) – Parameter name as used by SGU (maps to ‘parameternamn’ in API), e.g. ‘pH’, ‘Bly’, ‘Nitratkväve’, ‘Klorid’

  • national_site_id (int | list[int] | None) – Optional national sampling site ID(s) to filter by

  • site_id (str | list[str] | None) – Optional site identifier(s) to filter by

  • site_name (str | list[str] | None) – Optional site name(s) to filter by

  • tmin (str | datetime | None) – Start time (ISO string or datetime object)

  • tmax (str | datetime | None) – End time (ISO string or datetime object)

  • limit (int | None) – Maximum number of results to return

  • **kwargs (Any) – Additional query parameters

Return type:

AnalysisResultCollection

Returns:

Typed collection of groundwater chemistry analysis results

Raises:

ValueError – If more than one site identifier is provided, or if any site is not found in the lookup

Example

>>> from sgu_client import SGUClient
>>> client = SGUClient()
>>>
>>> # get all lead measurements since 2020
>>> results = client.chemistry.get_results_by_parameter(
...     parameter="Bly",
...     tmin="2020-01-01",
... )
>>>
>>> # get pH measurements for a specific site
>>> results = client.chemistry.get_results_by_parameter(
...     parameter="pH",
...     national_site_id=359366,
...     tmin="2020-01-01",
...     tmax="2021-01-01"
... )
>>>
>>> # ... or multiple sites
>>> results = client.chemistry.get_results_by_parameter(
...     parameter="pH",
...     national_site_id=[359366, 378865]
... )

pivot_by_parameter(**kwargs) → pd.DataFrame#

Pivot analysis results by parameter for easier time series analysis.

This creates a wide-format DataFrame where each chemical parameter becomes a column, making it easy to analyze multiple parameters over time.

Parameters:

  • values – Column to use for values (default: ‘measurement_value’)

  • index – Column to use as index (default: ‘sampling_date’)

  • columns – Column to pivot into columns (default: ‘parameter_name’)

  • aggfunc – Aggregation function if there are duplicate index/column pairs (default: ‘mean’). Can be ‘mean’, ‘median’, ‘first’, ‘last’, etc.

Returns:

Pivoted DataFrame with parameters as columns.

Example

>>> from sgu_client import SGUClient
>>> client = SGUClient()
>>>
>>> results = client.chemistry.get_results_by_site(359366)
>>> df_pivot = results.pivot_by_parameter()
