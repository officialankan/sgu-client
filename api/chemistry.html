Groundwater chemistry#

Water quality analyses from SGU’s Grundvattenkvalitet, analysresultat och provplatser (version 2) API, available as client.chemistry. See Groundwater chemistry for a walkthrough.

get_sampling_sites(bbox=None, datetime=None, limit=None, filter_expr=None, sortby=None, **kwargs)[source]#

Get groundwater chemistry sampling sites.

This method is used internally by convenience functions like get_sampling_site_by_name() by constructing filter expressions. A user may also do this, but readability is greater when using the built-in convenience functions.

Parameters:

  • bbox (list[float] | None) – Bounding box as [min_lon, min_lat, max_lon, max_lat]

  • datetime (str | None) – Date/time filter (RFC 3339 format or interval)

  • limit (int | None) – Maximum number of features to return (paginated automatically)

  • filter_expr (str | None) – CQL filter expression

  • sortby (list[str] | None) – List of sort expressions (e.g., [‘+name’, ‘-date’]) Note: the SGU v2 chemistry API currently ignores sortby; features are returned in the server’s default order.

  • **kwargs (Any) – Additional query parameters

Return type:

SamplingSiteCollection

Returns:

Typed collection of groundwater chemistry sampling sites

get_sampling_site_by_name(site_id=None, site_name=None, national_site_id=None, **kwargs)[source]#

Convenience function to get a sampling site by any site identifier.

Parameters:

  • site_id (str | None) – Site identifier (maps to ‘platsbeteckning’ in API)

  • site_name (str | None) – Site name (maps to ‘provplatsnamn’ in API)

  • national_site_id (int | None) – National sampling site ID (maps to ‘nationellt_provplatsid’ in API)

  • **kwargs (Any) – Additional query parameters (e.g., limit)

Return type:

SamplingSite

Returns:

Typed groundwater chemistry sampling site

Raises:

  • SGUNotFoundError – If no site matches.

  • SGUAmbiguousError – If several sites match.

  • ValueError – If not exactly one identifier is provided.

Example

>>> from sgu_client import SGUClient
>>> with SGUClient() as client:
...     # find site by id
...     site = client.chemistry.get_sampling_site_by_name(site_id="TTK-442-M")
...     # find site by name
...     site = client.chemistry.get_sampling_site_by_name(site_name="Lena")
...     # find site by national site id
...     site = client.chemistry.get_sampling_site_by_name(
...         national_site_id=359366
...     )
...     print(site.properties.municipality)

get_results_by_site(national_site_id=None, site_id=None, site_name=None, tmin=None, tmax=None, limit=None, **kwargs)[source]#

Get analysis results for a specific site with optional time filtering.

Analysis results are linked to sampling sites by national_site_id, which is the recommended (and fastest) way to identify a site. Using site_id or site_name requires an additional API request to look up the site.

Parameters:

  • national_site_id (int | None) – National sampling site ID (maps to ‘nationellt_provplatsid’ in API)

  • site_id (str | None) – Site identifier (maps to ‘platsbeteckning’ in API)

  • site_name (str | None) – Site name (maps to ‘provplatsnamn’ in API)

  • tmin (str | datetime | None) – Start time (ISO string or datetime object)

  • tmax (str | datetime | None) – End time (ISO string or datetime object)

  • limit (int | None) – Maximum number of results to return

  • **kwargs (Any) – Additional query parameters

Return type:

AnalysisResultCollection

Returns:

Typed collection of groundwater chemistry analysis results

Raises:

  • SGUNotFoundError – If a site_id or site_name matches no site.

  • SGUAmbiguousError – If a site_id or site_name matches several sites.

  • ValueError – If not exactly one of national_site_id, site_id or site_name is provided, or if the looked-up site has no national_site_id.

Example

>>> from sgu_client import SGUClient
>>> from datetime import datetime, timezone
>>> with SGUClient() as client:
...     # get all results for a site
...     results = client.chemistry.get_results_by_site(359366, limit=100)
...     # get results with time filtering
...     results = client.chemistry.get_results_by_site(
...         359366,
...         tmin=datetime(2020, 1, 1, tzinfo=timezone.utc),
...         tmax=datetime(2021, 1, 1, tzinfo=timezone.utc)
...     )
get_results_by_sites(national_site_id=None, site_id=None, site_name=None, tmin=None, tmax=None, limit=None, **kwargs)[source]#

Get analysis results for multiple sites with optional time filtering.

Analysis results are linked to sampling sites by national_site_id, which is the recommended (and fastest) way to identify sites. Using site_id or site_name requires an additional API request to look up the sites.

Parameters:

  • national_site_id (list[int] | None) – List of national sampling site IDs (maps to ‘nationellt_provplatsid’ in API)

  • site_id (list[str] | None) – List of site identifiers (maps to ‘platsbeteckning’ in API)

  • site_name (list[str] | None) – List of site names (maps to ‘provplatsnamn’ in API)

  • tmin (str | datetime | None) – Start time (ISO string or datetime object)

  • tmax (str | datetime | None) – End time (ISO string or datetime object)

  • limit (int | None) – Maximum number of results to return

  • **kwargs (Any) – Additional query parameters

Return type:

AnalysisResultCollection

Returns:

Typed collection of groundwater chemistry analysis results

Raises:

  • SGUNotFoundError – If any site_id or site_name matches no site.

  • ValueError – If not exactly one of national_site_id, site_id or site_name is provided, or if a looked-up site has no national_site_id.

Example

>>> from sgu_client import SGUClient
>>> with SGUClient() as client:
...     # get results for multiple sites
...     results = client.chemistry.get_results_by_sites(
...         [359366, 378865],
...         tmin="2020-01-01T00:00:00Z",
...         tmax="2021-01-01T00:00:00Z",
...         limit=1000
...     )
...     print(f"Found {len(results.features)} analysis results")
get_results_by_parameter(parameter, national_site_id=None, site_id=None, site_name=None, tmin=None, tmax=None, limit=None, **kwargs)[source]#

Get analysis results filtered by chemical parameter (e.g., pH, nitrate).

This convenience method makes it easy to retrieve all measurements for a specific chemical parameter, optionally filtered by site(s) and time range. Sites are identified the same way as in get_results_by_site(): national_site_id is recommended, while site_id or site_name require an additional API request.

Parameters:

  • parameter (str) – Parameter name as used by SGU (maps to ‘parameternamn’ in API), e.g. ‘pH’, ‘Bly’, ‘Nitratkväve’, ‘Klorid’

  • national_site_id (int | list[int] | None) – Optional national sampling site ID(s) to filter by

  • site_id (str | list[str] | None) – Optional site identifier(s) to filter by

  • site_name (str | list[str] | None) – Optional site name(s) to filter by

  • tmin (str | datetime | None) – Start time (ISO string or datetime object)

  • tmax (str | datetime | None) – End time (ISO string or datetime object)

  • limit (int | None) – Maximum number of results to return

  • **kwargs (Any) – Additional query parameters

Return type:

AnalysisResultCollection

Returns:

Typed collection of groundwater chemistry analysis results

Raises:

  • SGUNotFoundError – If any site_id or site_name matches no site.

  • ValueError – If more than one of national_site_id, site_id or site_name is provided, or if a looked-up site has no national_site_id.

Example

>>> from sgu_client import SGUClient
>>> with SGUClient() as client:
...     # get all lead measurements since 2020
...     results = client.chemistry.get_results_by_parameter(
...         parameter="Bly",
...         tmin="2020-01-01",
...     )
...     # get pH measurements for a specific site
...     results = client.chemistry.get_results_by_parameter(
...         parameter="pH",
...         national_site_id=359366,
...         tmin="2020-01-01",
...         tmax="2021-01-01"
...     )
...     # ... or multiple sites
...     results = client.chemistry.get_results_by_parameter(
...         parameter="pH",
...         national_site_id=[359366, 378865]
...     )

pivot_by_parameter(values='measurement_value', index='sampling_date', columns='parameter_name', aggfunc='mean')[source]#

Pivot analysis results by parameter for easier time series analysis.

This creates a wide-format DataFrame where each chemical parameter becomes a column, making it easy to analyze multiple parameters over time.

Parameters:

  • values (str) – Column to use for values (default: ‘measurement_value’)

  • index (str) – Column to use as index (default: ‘sampling_date’)

  • columns (str) – Column to pivot into columns (default: ‘parameter_name’)

  • aggfunc (str) – Aggregation function if there are duplicate index/column pairs (default: ‘mean’). Can be ‘mean’, ‘median’, ‘first’, ‘last’, etc.

Return type:

DataFrame

Returns:

Pivoted DataFrame with parameters as columns.

Example

>>> from sgu_client import SGUClient
>>> with SGUClient() as client:
...     results = client.chemistry.get_results_by_site(359366)
...     df_pivot = results.pivot_by_parameter()
...     # now df_pivot has columns like 'pH', 'Nitratkväve', 'Klorid', etc.
