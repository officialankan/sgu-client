Client#

SGUClient is the entry point for every request. Endpoints are grouped by domain on its attributes:

Attribute

Client

client.levels.observed

ObservedGroundwaterLevelClient (Observed groundwater levels)

client.levels.modeled

ModeledGroundwaterLevelClient (Modeled groundwater levels)

client.chemistry

GroundwaterChemistryClient (Groundwater chemistry)

See Getting started for an introduction.

SGUClient#

class SGUClient(config=None)[source]#

Main client for interacting with SGU API.

This is the primary interface users will interact with.

Use it as a context manager so the HTTP session is closed when you are done. If the client has to outlive a with block, call close() yourself.

Example

>>> with SGUClient() as client:
...     stations = client.levels.observed.get_stations()
...     measurements = client.levels.observed.get_measurements()

>>> # With custom config
>>> config = SGUConfig(timeout=60, log_level="DEBUG")
>>> with SGUClient(config=config) as client:
...     stations = client.levels.observed.get_stations()

LevelsClient#

class LevelsClient(base_client)[source]#

Client for accessing groundwater level data.

Provides access to both observed and modeled groundwater levels through a hierarchical API structure.

Example

>>> with SGUClient() as client:
...     stations = client.levels.observed.get_stations()
...     areas = client.levels.modeled.get_areas()
...     levels = client.levels.modeled.get_levels()
